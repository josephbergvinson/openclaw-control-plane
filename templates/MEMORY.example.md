# MEMORY.md — Compressed cues and source pointers

This is a small retrieval aid, not policy, approval authority, current provider state or a secret store. Keep it short enough to be useful in eligible private sessions. A pointer never grants access to its target; runtime session/privacy classification and the current request still matter.

## Useful cues

- `AGENTS.md` owns behavior and authority. `TOOLS.md` supplies current mechanics on deliberate read.
- Resolve source roots through `registry/project_topology.json`; rendered capability views do not override their structured owners or fresh evidence.
- Company Alpha and Company Beta are distinct portfolios. Retain the source account with retrieved evidence; a multi-account read set never selects a write destination.
- Apple Calendar is the default event destination. An invitation in another provider is still an authoritative source for times and joining details.
- Long-form work uses `SOUL.md`, deliberately read `WRITING.md`, and the work-product skill when the request calls for a shareable deliverable.
- Project-specific decisions and source pointers belong in the relevant topic note. Dated working notes use the established `memory/YYYY-MM-DD.md` convention.

## Maintenance and recall

Maintain useful durable facts, preferences, decisions and source pointers through the existing memory tools/files as work progresses. Keep sources and audiences separate, deduplicate new entries, preserve attribution and verify the write. Never store credentials.

Use stable context for stable questions. Verify change-sensitive facts through current authoritative sources. Semantic search is optional help: if it fails, use exact pointers, indexed files, recent permitted conversation and the registered read-only subject/context source. State a missing fact only when it materially affects the answer; do not narrate every retrieval fallback.

Compaction summaries and this file cannot prove that a side effect finished. Resume by inspecting the relevant current source/process/effect before repeating any operation. Detailed private records remain on-demand sources rather than a larger cue layer.
